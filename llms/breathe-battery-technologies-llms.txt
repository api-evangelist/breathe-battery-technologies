# Breathe Battery Technologies

> Breathe Battery Technologies is a UK battery software company (Imperial College London spin-out, 2019) building physics-based battery simulation, cell design, and adaptive charging software for OEM and cell engineering teams. Its products are API-delivered and consumed through first-party Python client libraries and MATLAB/Simulink integration, backed by a token-authenticated cloud service.

This llms.txt was generated by the API Evangelist enrichment pipeline from the provider's public developer surface. No provider-published /llms.txt was found (docs host returns 404).

## Products

- [Breathe Design](https://www.breathebatteries.com/products/breathe-design): API-delivered battery cell design and simulation platform.
- [Breathe Simulate](https://docs.breathebatteries.com/breathe-simulate-documentation/): Validated physics-based battery performance and degradation modelling in Python and MATLAB/Simulink.
- [Breathe Charge](https://www.breathebatteries.com/): Embedded adaptive charging software (shipping in Volvo EVs).

## APIs

- [Breathe Simulate API reference](https://docs.breathebatteries.com/breathe-simulate-documentation/api_breathe_design_model/): Retrieve batteries, battery formats, materials, OCV/aged-OCV, design parameters, run simulations. Token-authenticated; consumed via the Python SDK.

## SDKs / Packages

- [breathe-simulate (PyPI)](https://pypi.org/project/breathe-simulate/): `pip install breathe_simulate` — Python client for the Breathe Simulate API.
- [breathe-design (PyPI)](https://pypi.org/project/breathe-design/): `pip install breathe_design` — Python client for the Breathe Design API.
